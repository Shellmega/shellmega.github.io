# 大一加入 Embodiment AI 实验室学习路线

## 一、已有优势

具备 NOIP 一等奖基础，通常已经掌握：

- C++ 和数据结构
- 算法设计与复杂度分析
- 抽象建模和调试能力

接下来重点补充：

> 数学基础 + 机器学习 + 机器人系统 + 实验工程

## 二、学习重点

### 1. AI 工具链

- Python
- NumPy
- PyTorch
- OpenCV
- Linux
- Git
- CUDA 基础
- CMake

目标：能够独立完成数据处理、模型训练、结果分析和代码复现。

### 2. 数学

- 线性代数：矩阵、SVD、旋转矩阵、四元数、坐标变换
- 概率论：高斯分布、贝叶斯、卡尔曼滤波
- 优化：梯度下降、最小二乘、非线性优化
- 控制：PID、状态空间、轨迹跟踪

### 3. 机器人

- ROS 2
- TF 坐标变换
- RViz
- URDF
- 正逆运动学
- 雅可比矩阵
- 碰撞检测
- 运动规划
- MoveIt 2

### 4. 计算机视觉

- 相机模型和标定
- 目标检测
- 语义分割
- 深度估计
- 点云
- AprilTag
- PnP
- 视觉里程计

### 5. 具身智能方向

选择一个方向深入：

- 机器人导航
- 运动规划
- 机械臂操作
- SLAM
- 强化学习
- 模仿学习
- 视觉语言动作模型
- Sim-to-Real

## 三、推荐学习路线

### 大一上

- Python、Linux、Git
- PyTorch 和 OpenCV
- 线性代数、概率论
- 完成一个视觉项目

### 大一下

- ROS 2
- 机器人坐标系
- Gazebo、MuJoCo 或 PyBullet
- 完成移动机器人避障项目

### 大二上

选择一个方向深入，完成：

- 论文阅读
- 开源代码复现
- 对比实验
- 实验报告

## 四、推荐项目

1. A*、RRT 机器人路径规划可视化
2. ROS 2 移动机器人避障
3. 摄像头目标检测与位置估计
4. 机械臂逆运动学与抓取
5. 基础模仿学习
6. 视觉语言机器人仿真

## 五、六个月目标

完成一个完整项目：

> 摄像头识别目标，经过坐标转换后，控制仿真机器人执行简单动作。

项目应包含：

- PyTorch 或 OpenCV
- ROS 2
- 坐标转换
- 仿真运行
- 结果视频
- GitHub README
- 失败案例分析

## 六、联系实验室前的准备

准备：

- 一页简历
- 一个可运行的 GitHub 项目
- 一篇论文阅读笔记
- 对实验室近期工作的了解

联系老师时说明：

- 自己的 NOIP 一等奖基础
- 已掌握的工具
- 已完成的项目
- 感兴趣的研究方向
- 希望从代码复现、数据处理或仿真实验开始

## 七、优先级

1. Python、PyTorch、Linux、Git
2. OpenCV、ROS 2、数学基础
3. 机器人学、控制、运动规划
4. 强化学习、模仿学习、VLA
5. 论文复现和真实机器人部署

最重要的是：不要只刷算法题，要尽快完成一个能运行、能展示、能复现的机器人项目。
