## 从 Wordpress 到 Hexo

在搭建这个博客之前，我尝试过多种方案：

<!-- more -->

### 方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| Wordpress | 功能完善、插件丰富 | 臃肿、需要维护数据库 |
| Ghost | 界面简洁 | 自部署成本较高 |
| Jekyll | GitHub 原生支持 | 配置较复杂 |
| Hexo | 速度快、Markdown 原生 | 主题生态相对较小 |

### 最终选择：Hexo

选择 Hexo 的核心原因：

1. **速度**：基于 Node.js，生成速度极快
2. **Markdown 原生**：写作体验极佳
3. **GitHub Pages 部署**：静态站点，零成本部署
4. **极简主题**：Linen 主题完美契合极简需求

### 设计理念

本站采用极简黑白风格，核心理念是：

- **内容优先**：去除一切干扰阅读的元素
- **黑白配色**：经典耐看，不会过时
- **响应式**：在任何设备上都有良好阅读体验
- **快速加载**：纯静态，无冗余脚本

### 结语

工具只是载体，内容才是核心。希望这个博客能成为一个安静的写作空间。
